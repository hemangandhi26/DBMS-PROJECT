# DBMS-PROJECT

A Database Management System (DBMS) project developed to demonstrate database design, data storage, querying, and management operations using SQL and relational database concepts.

---

## Overview

This project focuses on implementing core DBMS concepts including:
- Database creation
- Table relationships
- SQL queries
- Data insertion and retrieval
- Constraints and normalization
- CRUD operations

The project demonstrates how databases are used to efficiently manage and organize large amounts of structured data.

---

## Features

- Relational database design
- SQL query implementation
- Data management operations
- Primary and foreign key relationships
- Normalized database structure
- Record insertion, deletion, update, and retrieval

---

## Technologies Used

- SQL

- DBMS Concepts
